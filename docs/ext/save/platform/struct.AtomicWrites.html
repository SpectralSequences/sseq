Struct AtomicWrites 

Source 
struct AtomicWrites {
    inner: FilesystemStore,
}
Expand description

A [FilesystemStore] whose writes replace each file atomically.

FilesystemStore::set truncates the file before writing it, and the sharding codec rewrites a whole shard on every store, so a crash mid-write would lose every element already in the shard. Here each value goes to a temporary key that is then renamed over the destination. A crash leaves at most an orphaned temporary file, which nothing reads.

impl AtomicWrites

Source

fn temporary_key(key: &StoreKey) -> Result<StoreKey, StorageError>

The temporary key for key in this process.

One name per destination, rather than one per write, because FilesystemStore keeps a lock for every key it has written and never frees them.

Source

fn write_lock(&self, key: &StoreKey) -> Arc<Mutex<()>> ⓘ

The lock serializing this process’s writes to key, which share its temporary key.

Keyed by file path, so separate stores opened on one directory share it. Threads can write one key at the same time, e.g. when they create the same group.
