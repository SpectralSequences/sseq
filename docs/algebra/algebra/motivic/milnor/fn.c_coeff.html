fn c_coeff(s: &[u32], r: &[u32]) -> u32
Expand description

The coefficient $c(S, R)$ of Notation 3.3 / Theorem 3.4, reduced mod 2.

$c(S, R) = \prod_{n \ge 1} \binom{\lfloor \sum_{i=0}^{n-1} 2^{i-n}(s_i - r_i)\rfloor}{r_n}$ when $r_0 = 0$, and $0$ otherwise. The inner floor is computed exactly with integer (Euclidean) division: $\lfloor \sum_{i=0}^{n-1} 2^{i-n}(s_i-r_i)\rfloor = \lfloor (\sum_{i=0}^{n-1} (s_i-r_i)2^i) / 2^n \rfloor$. Each factor is Binomial::binomial2, which is $0$ when the top is negative or below the bottom.
